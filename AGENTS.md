# AGENTS.md: rules for AI agents in this repository

This repository is a team entry to More than a Hack 2027. The match data is licensed for the
competition only, and its terms forbid uploading, disclosing or otherwise making available the
videos, the datasets, or any extract of them to a third-party hosted or cloud-based LLM. Every
agent that runs on a hosted model falls under that clause. These rules make sure that working
with an agent never breaks it.

## 1. Never read the match data

- Do not open, print, sample, plot or summarise any file under `data/`: the tactical and broadcast
  bundles and every per-frame artefact derived from them. File names and sizes are fine;
  contents are not.
- Do not look at frames or listen to audio of the match videos.
- In Claude Code, `.claude/settings.json` denies the read tools on these paths. Shell commands and
  other agents are not blocked by it, so this rule is the real guard.

## 2. Only aggregates leave a run on the match data

- A script that reads the match data prints aggregates only: validation pass or fail, label
  counts, possession count and mean duration, and scores against the public five-minute ground
  truth.
- Its entry point runs through `possession.safety.run_safely`, which reports an exception's type
  and location but never its message, because a message can quote a line of tracking.
- A person runs such scripts and passes back only their aggregate output.

## 3. Competition rules that shape the code

`docs/challenge/RULES.md` is authoritative. In short:

- Labels come from an algorithm. No hand labels on this match, for any purpose, including
  validating a model or choosing a parameter.
- The public five-minute ground truth only checks that the pipeline is correct. It never chooses
  between variants and is never training data.
- Every model and parameter choice is made on other matches, and the evidence is recorded.
- No human-produced data about this match: event data, corrected tracking, annotations.
- Never open a pull request against `metrica-sports/more-than-a-hack-2027`.

## 4. Reproducibility

- The submission must be regenerated byte for byte from a clean clone: inference on CPU,
  versions pinned in `requirements.txt`, fixed seeds, CSV written with `newline="\n"`.
- Committed files use LF line endings (`.gitattributes`).

## 5. Never publish the data

- `data/`, `*.mp4` and the bundle files are gitignored, and `.githooks/pre-commit` refuses them.
  Run `git config core.hooksPath .githooks` once per clone.
